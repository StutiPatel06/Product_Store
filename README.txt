PRODUCT STORE - SUBMISSION VERSION

This version uses the product photographs from the previously generated website mockup/reference.

Run in VS Code:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal.
4. Run: npm.cmd install
5. Run: npm.cmd run dev
6. Open the localhost link shown by Vite.

The images are stored locally in public/images, so no internet connection is required for the product images.
